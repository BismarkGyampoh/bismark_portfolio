# DESIGN REVISION: MAKE THE PORTFOLIO LIGHTER, CLEANER AND MORE PROFESSIONAL

Review the existing portfolio UI/UX design system and revise its visual direction.

The current interface is too dark. I want a brighter, cleaner and more welcoming professional portfolio.

IMPORTANT: Do not rebuild the project or modify its architecture. This is a visual design revision only.

## 1. NEW DESIGN DIRECTION

Adopt a light-first modern corporate aesthetic.

The website should feel:
- Bright.
- Clean.
- Professional.
- Elegant.
- Modern.
- Approachable.
- Well-structured.

Use white and light neutral backgrounds as the dominant visual elements.

Do not make dark backgrounds the dominant visual feature.

## 2. UPDATED COLOUR PALETTE

Use these design tokens:

Primary background: #FFFFFF
Secondary background: #F8FAFC
Section background: #F1F5F9
Primary text: #172033
Secondary text: #64748B
Primary accent: #2563EB
Soft accent: #DBEAFE
Borders: #E2E8F0

Dark mode should remain available as an optional theme.

Set light mode as the default theme for first-time visitors.

Preserve user theme preferences.

## 3. VISUAL IMPROVEMENTS

- Increase whitespace where necessary.
- Use clear typography and strong text hierarchy.
- Avoid large dark background sections.
- Use subtle shadows instead of heavy borders.
- Keep cards clean and light.
- Use blue accents strategically.
- Reduce unnecessary gradients.
- Avoid excessive animations.
- Maintain consistent spacing.
- Make the interface visually balanced.

## 4. COMPONENT REVISIONS

Review and update:
- Navigation bar.
- Buttons.
- Cards.
- Form inputs.
- Section headings.
- Background surfaces.
- Borders.
- Theme toggle.
- Mobile navigation.

Ensure all components follow the new visual direction.

## 5. RESPONSIVENESS

Maintain excellent presentation on desktop, tablet and mobile.

Do not sacrifice readability or usability to achieve the visual design.

## 6. VERIFICATION

After making the revisions:

1. Run the application.
2. Inspect all existing UI components.
3. Verify that light mode is the default.
4. Test dark mode.
5. Check text contrast.
6. Test responsiveness.
7. Run the production build.

Update DESIGN_SYSTEM.md to reflect the revised visual identity.

Do not begin Part 4.

Provide a report of the visual changes and wait for approval.
